# IMP Phase Roadmap

## Phase 1 (0–3 months) — Foundation
**Status as of April 2026: IN PROGRESS**

Goals:
- Auth + subscriptions live ← B-01 (BillingController) and B-02 (Auth) — B-02 complete, B-01 in progress
- 3 Pro users (breakeven)
- Map Shell v2 complete
- Person Intelligence Profile fixed
- Activate 7 ComingSoon pages
- First press mention

Blockers: BillingController + Stripe (B-01)

## Phase 2 (3–9 months) — Oracle & Automation
Goals:
- 50 obsessed weekly active users
- Oracle live with 20 machines
- Perplexity + Claude + n8n automation running
- Strategy Lab shipped
- AI Analyst Avatars live
- IMP Briefing API launched
- PersonPowerIndex + CompositeRiskIndex controllers live
- GDELT ingest
- First enterprise client

New tables: AnalystCalibration, TradeSignal, EntityMarketSignal, TimelineProbabilityHistory, MarketPriceSnapshot

## Phase 3 (9–18 months) — Intelligence Platform
Goals:
- 500 paid users
- Series A fundable
- Bot Marketplace open
- Supply Chain Due Diligence product
- Geopolitical Risk API
- Portfolio Simulation live
- EUR/USD signal pipeline
- Polymarket CLOB full integration
- Observatory pilot with one institutional partner

New tables: UserPosition, PortfolioRiskSnapshot, EntityExposure, TradeLog, PriceBar, BacktestResult, PolymarketMarketLink, ResolutionImpactLog

## Phase 4 (18–36 months) — Data Moat
Goals:
- 100+ resolved predictions per machine
- Correlation Discovery Engine live
- Fine-tuning dataset valuable
- Regime-conditioned ensemble weights
- GNN upgrade (Apache AGE evaluation)
- Acquisition conversations begin

## Exit (Year 7–9)
- Target: $300M–$1B acquisition
- Acquirers: Bloomberg, S&P, Palantir, Mastercard
- Catalyst: Correlation Discovery Engine — 24 months of validated predictions with causal graph paths

## Funding Milestones
